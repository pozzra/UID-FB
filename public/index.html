1. តើ UID Facebook ជាអ្វី? ប្រើសម្រាប់អ្វី?
UID (User ID) គឺជាលេខសម្គាល់តែមួយគត់សម្រាប់គណនីនីមួយៗនៅលើ Facebook (អ្នកប្រើប្រាស់, ផេក, ក្រុម, ការបង្ហោះ)។ UID មិនដែលផ្លាស់ប្តូរទេ បើទោះបីជាប្តូរឈ្មោះ ឬ Vanity Username ក៏ដោយ។
2. តើតំណភ្ជាប់ Facebook ប្រភេទណាខ្លះដែលគាំទ្រ?
ប្រព័ន្ធគាំទ្រ 100% គ្រប់ទម្រង់តំណភ្ជាប់ Facebook សព្វថ្ងៃ៖
  • Vanity / Username Link: https://www.facebook.com/zuck
  • Profile ID Link: https://www.facebook.com/profile.php?id=1000...
  • Fanpage Link: https://www.facebook.com/Meta
  • Group Link: https://www.facebook.com/groups/123456789/
  • People Profile Link: https://www.facebook.com/people/Name/1000.../
  • Short Link: fb.me/..., fb.com/...
  • Post / Reels Link: facebook.com/share/p/...
3. តើឧបករណ៍នេះមានសុវត្ថិភាពដែរឬទេ?
សុវត្ថិភាព 100%។ អ្នកមិនចាំបាច់ចូលគណនី Facebook របស់អ្នកឡើយ មិនទាមទារ Cookie ឬ Access Token ទេ។
